# Résumé PDF

1. Export your résumé as a PDF.
2. Name it **`YOUR_RESUME_HERE.pdf`** (or pick another name and update `resume_pdf_path` in `docs/_config.yml`).
3. Place the file in this folder (`docs/assets/documents/`).
4. Commit and push — the **Resume** link in the header opens this PDF in a new tab.

The repository intentionally does not ship a real résumé file; add yours locally before publishing.
